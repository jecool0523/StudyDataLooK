# 제8회 교육 공공데이터 AI 활용대회 제출 코드
학생 맞춤형 사이버폭력 교육 데이터 생성 서비스 LooK 개발을 위해 사용된 코드들입니다.

- crawler 파일은 학교별 dc계시판을 크롤링하기 위해.
- data 파일은 크롤링한 데이터를 보관하기 위해.
- release는 크롤링 코드를 다른 pc에서 실행하기 위해.
- hate_detector 및 models는 크롤링한 글들에서 혐오표현을 감지 및 분류하기 위해 만들어졌습니다.

대부분의 코드는 python으로 작성되었고.
requests, selenium, transformer를 기반으로 제작되었습니다.
